# Password Audit Home Lab

A hands-on password auditing lab conducted in a controlled 
home lab environment using Kali Linux and Metasploitable 2.

## Quick Summary
- Performed nmap scan revealing 23 open ports
- Established SSH connection and extracted password hashes
- Used John the Ripper with rockyou wordlist
- Cracked 4 passwords including root within 5 minutes

## Tools Used
nmap, SSH, SCP, unshadow, rockyou wordlist, John the Ripper
